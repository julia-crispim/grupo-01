# Grupo 01 — Caso Saúde: rede municipal de atenção à saúde

## Caso

**Caso 2 — Saúde: rede municipal de atenção à saúde**

A secretaria municipal de saúde vai unificar os sistemas da rede municipal, envolvendo unidades básicas de saúde (UBS), unidades de pronto atendimento (UPA), hospital municipal de referência, central de regulação de leitos, farmácia municipal e vigilância epidemiológica.

O sistema atual é fragmentado entre diferentes unidades e existem sistemas legados que precisam continuar funcionando durante o período de transição.

## Envelope

**Envelope A**

- Startup contratada para entregar a primeira versão em 6 meses.
- Equipe com 6 desenvolvedores.
- Sem equipe de operação.
- Caixa disponível para 6 meses.
- Nuvem pública paga por uso.
- Exigência principal: entregar rápido e barato sem criar um problema impossível de manter depois.
